# Iteration 3 — план: новые элементы (по мотивам SOOTH) и улучшение карты

Цель: превратить «дом + ферма + 5 концовок» в плотную стелс-головоломку с длинными цепочками
«предмет → объект → результат», несколькими маршрутами и второй мини-локацией, не теряя кооп-мультиплеер
и PS1/VHS-стиль. Всё — наши собственные загадки и имена (SOOTH — только ориентир по структуре).

## 0. Принципы (для каждой фичи)

- Хост-авторитет: каждая механика = `MatchHost.<Feature>.cs` + `MatchWorld.<Feature>.cs` + сообщения в `Msg`
  (клиент → хост только `*Req`, добавлять в `MsgRules.FromClient`).
- Новые значения `ItemType` / `AdminCmd` / `EndingId` — только в конец enum; при смене формата сообщений
  поднимать `GameInfo.ProtocolVersion`.
- Коды и раскладка предметов рандомизируются от `Settings.Seed` (один забег ≠ другой), подсказки — в записках.
- Всё процедурное (MapBuilder / PropLibrary / ItemMeshFactory, текстуры из `Tools/AssetPipeline`), звуки — `gen_*.py`.
- Каждая фича: отдельный коммит, проверка `Tools/CompileCheck`, превью-рендер / `map/sim`, команда в админ-панели.

## 3. Новые головоломки-цепочки (на существующих точках карты)

1. **Весы мясника** (кухня/морозилка): положить N кусков → весы ломаются (громко!) → Gear.
2. **Напольные часы** (`GrandfatherClock` уже есть): Gear → часы → выставить время из записки → тайный ход на чердак.
3. **Верёвка**: Alcohol → верёвка → Lighter → падает ящик → Wire Cutters.
4. **Раковина**: Drain Cleaner → раковина 2 этажа → Hex Key в чёрной луже подвала.
5. **Щиток / вентилятор**: Screwdriver → щиток, Wire Cutters → провод → вентилятор в вентиляции встаёт → новый маршрут.
6. **Пар в котельной** (`FurnaceRoom`): лебёдка колодца → Valve → пар перекрыт → проход к бункеру.
7. **Предохранители** (`FuseBox` расширить): 4 номинала, сумма ≤ лимит → питание бункера/радио.
8. **Банка**: 3 батарейки → открывалка → банка → ключ входной двери (новый выход «через дверь»).
9. **Яма на чердаке**: Plank → переход в комнату с костями → Shed Key.
10. **Сарай**: Shed Key → Duct Tape → чинит провод вентилятора на чердаке → падает батарейка.

Каждая — шумная/рискованная по-своему (Омар слышит весы, лебёдку, стекло).

## 4. Карта — новые зоны

| Зона | Содержимое | Связь |
|---|---|---|
| **Чердак** | коридор, детская (враг Baby), комната с костями, яма с колючкой, вентилятор, выход вентиляцией во двор | тайный ход за часами |
| **Подвал+** | котельная с паром, щиток, чёрная лужа, дверь бункера | лестница + вентиляция |
| **Гараж** | фургон Омара (разбить окно), верстак, доски | кухня / двор |
| **Двор** | клетки с пленниками, сарай, колодец с лебёдкой, загон | чердак (вентиляция), задняя дверь |
| **Бункер** (переделка `Shelter`) | 2 уровня: склад, морозилка с запиской, загон, пульт отключения с двумя ключами | дверь в подвале, код |

Улучшение существующей карты:
- 2–3 маршрута к каждой цели (дверь / вентиляция / окно), сквозная вентиляционная сеть с укрытиями.
- Укрытие каждые ~15 м на маршрутах; тёмные и освещённые участки чередуются.
- Ориентиры: свет в окнах, ТВ, звуки (часы, насос, генератор) — чтобы не терялись.
- Навмеш Омара/бабушки на новых этажах, Омар пригибается в низких проходах чердака.
- Плотность декора по комнатам (каждая — своя история: детская, кладовая, морозилка).
- Баланс времени: полный забег 20–35 мин на Normal; проверка достижимости в `map/sim`.

## 5. NPC и враги

- **Пленники** (2–3 случайных в клетках двора/сарая): освободить → идут за игроком или прячутся →
  награда (предмет / код / открывают дверь изнутри). Умирающие / раненые — атмосфера и записки.
- **Baby** (чердак + вентиляция): медленный, слепой, реагирует на шум; в вентиляции опасен.
- **Собака** во дворе: бежит на бег/свет, отвлекается мясом, будит Омара лаем.
- Омар: реакции на новые шумы (весы, стекло, лебёдка), патруль новых этажей, проверка тайного хода.

## 6. Концовки и прогресс

- Новая концовка **«Через дверь»** (ключ из банки) и **«Отключение»** (пульт бункера: 2 ключа + последовательности).
- Бонус к финальному экрану за освобождённых пленников; «Следователь» — собрать все записки.
- Существующие 5 концовок остаются; цепочки дают альтернативные пути к ним.

## 7. Опционально: пролог «Ночная смена»

Одиночный обучающий пролог на заправке (подмести, разложить товар, туалет, покупатели, белый фургон) →
похищение → загрузка матча. Отдельная маленькая сцена, учит управлению и стелсу.

перегруз загадками — каждая цепочка ≤ 3 шагов, подсказки в записках.
